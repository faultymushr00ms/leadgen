# FORGE Audit Reports

Daily data-quality audit for the FORGE lead gen CRM.
Generated by `scripts/run_daily_audit.sh` at 6:30 AM.
Read-only findings — never contains zone data.

## Files
- `data/reports/audit_latest.md` — most recent audit (human-readable)
- `data/reports/audit_latest.json` — most recent audit (machine-readable)
- `data/reports/audit_YYYY-MM-DD.*` — daily archives

## Checks run per zone
EXPIRED_ACTIVE · STALE_RENEWAL · TERM_NO_PROGRAM · AGG_NO_RATE ·
RATE_MISMATCH · RATE_CHANGE_NO_PREV · RATE_NO_SOURCE · STALE_60 ·
MUNI_IOU_NOTES · IOU_MUNI_NOTES · COOP_IOU_NOTES · COPY_RATE_MISMATCH ·
DOC_COUNT_MISMATCH
