# FORGE Audit Reports

Daily data-quality audit for the FORGE lead gen CRM.
Generated by `scripts/run_daily_audit.sh` at 6:30 AM.
Read-only findings — never contains zone data.

Owner: Claude scheduled routine (since 2026-11-17; replaces the previous bot).

## Files
- `data/reports/audit_latest.md` — most recent audit (human-readable)
- `data/reports/audit_latest.json` — most recent audit (machine-readable)
- `data/reports/audit_YYYY-MM-DD.*` — daily archives
- `data/reports/scan_YYYY-MM-DD.md` — day-over-day diff notes
- `data/reports/proposed_changes_latest.{md,json}` — data fixes waiting for owner approval (IDs P01…). Nothing here is applied to `main` until approved.
- `data/reports/proposed_changes_YYYY-MM-DD.*` — dated archives
